# 第二阶段独立评估协议 v1（2026-10-26）

本协议冻结评估方法，不代表已经获得独立标签或运行新一轮模型评估。源码基线为 `phishlens-local-v0.2.8-20261026` 与 `phishguard-local-20261026`；图库为 `b2fbae625ce37e37`，品牌相似度门槛 0.90、间距 0.04 保持原值。所有修改方案先在开发组比较，最终测试组不用于调阈值、选裁剪或补图库。

## 数据单位、类别与独立性

以一次有来源的原始页面采集为样本，以来源/模板连通组为划分单位。作者提供的 trainval/test 字段只记作来源信息，不自动成为本项目的训练/独立测试划分。类别为可重叠的角色：A 训练或图库参考，B 已开发/调试/观察模型输出，C 图库派生控制，D 尚可复核的候选，E 身份、目标或恶意性未核实。D 可以同时属于 E；不得将 D 数量当作已合格测试数量。

同一原图的复制、裁剪、放大、标注图、派生 HTML 与重复截图必须共享 provenance_group_id。字节 SHA、白底 RGBA 合成后的尺寸+RGB 像素 SHA、标准化 URL、作者域名字段及 dHash≤4 形成保守关联；dHash 近邻只表示待核对关系，不能证明语义重复。已知来源派生关系即使哈希不同也要合并。共享正常品牌 Logo 不等于页面整体重复；明确使用图库资产拼出的测试页属于 C，必须排除独立指标。

图像查重不能完整发现局部裁剪、换色、页面模板、相同钓鱼套件和时间近邻。候选在冻结之前还需复核模板/来源/采集时间及参考图来源。没有匹配到哈希不等于“无泄漏”。预训练 AWL/Siamese/OCR 的完整训练成员目前不具备可验证清单，必须报告这项未知，不能宣称绝对训练独立。

将 pilot 50 张和历史已经产生输出的 200 张及其关联组标为 B；不能换随机种子重新包装成独立测试。历史本地截图、第一至第四天演示、已知 P01705/P01020/P01182 的所有派生图留作开发/回归。另将 PhishGuard split_manifest.csv 中训练、验证和反复使用的测试域名/URL 标为联合评估排除关系；该域名键只是已有分组字段，不冒称新完成了完整公共后缀域名判定。

## 标签流程

标签至少分开保存：原始作者标签、采集时刻的恶意性、可见主要身份、次要品牌及角色、所声称的身份、被仿冒目标、登录/凭据表单上下文、截图质量。模型候选和预测不得填入人工真值列。未知品牌、混合页面和第三方标志允许“无单一主要品牌/未解决”，不是按最高分强选一个。

先进行不显示预测、候选分数和作者恶意标签的独立图像身份标注；两位复核者各自给出品牌/角色/框。随后核验已存档采集时间、来源证据、静态 HTML 表单归属和历史域名/跳转证据，讨论恶意性。正常页面也需采集时的合法身份及用途证据，不能只凭品牌官网外观判正常；普通登录框、相似域名或品牌词不足以判钓鱼。不访问样本真实网址，不执行原钓鱼 HTML，不输入真实表单数据。

恶意性推荐状态：unreviewed、author_only、corroborated_pending_adjudication、independently_verified、unresolved。两位复核一致只是证据之一，必须记录依据；分歧交第三方裁决，无法解决则从需要该真值的指标分母排除，并报告排除数量与原因。品牌真值可已确认而恶意性仍未知，两者资格分别计算。已有三例助手复核仍属临时开发标注，不自动升为独立验证。

冻结清单须包含 sample_id、source SHA、provenance_group_id、来源/许可/时间、标注者与日期、两份原意见、裁决、适用指标、场景标签、排除原因、模型/图库版本。使用清单的 SHA 作为版本；任何合并组或标签修订产生新版本，保留旧版。当前可提供空标签复核队列，不能代填真值。

## 场景和抽样

采用多标签场景，并指定一个主场景供不重叠汇总：

1. 清晰主要品牌 Logo；记录真实框和可读性。
2. 小型或低分辨率 Logo；记录原图像素宽高、页面比例、DPR、遮挡，分别统计原生小图与人工缩放图。派生缩放不能增加独立样本数。
3. 纯文字品牌登录声明，没有独立 Logo；区分标题、正文、页脚、表单标签及 OCR/DOM 来源。
4. 多品牌混合及第三方支付图标；允许无唯一目标，分别标出主要身份和第三方角色。
5. 正常品牌介绍、页脚归属及第三方登录负例；包括存在密码框但品牌文字属于另一表单的难例。
6. 当前图库之外的未知品牌、无品牌和不应匹配的相似字标；记录“图库外”的版本依据。
7. 正常登录与真实钓鱼登录，按身份/恶意性双重核验。合法自托管软件、授权登录和第三方托管单列。

下一步起步目标是新增或复核约 200 个不重叠来源组（拟正常/拟钓鱼各约 100），并覆盖各场景。该数字是采集目标，不是本次已合格样本数，也不足以证明低误报率。标签完成后在组级按类别/主场景分层，以固定种子 `phase2-evaluation-v1` 划出开发验证与锁定测试；每组只分配一次，跨品牌/域名/模板/时间有重叠的组不能跨集合。最终组成员、选择函数、随机种子和 SHA 一并存档。候选不足时报告缺口，不从已观察组补齐。

## 模态与执行条件

截图+URL 可以用于品牌视觉诊断，不足以重放浏览器原始拦截。作者恶意标签不得用来伪造 has_password_input 或凭据关联。完整判定需同次截图、视口/DPR、实际 DOM 结构信号、凭据容器位置、域名及采集时上下文；只保存静态结构/标签，不保存账号、密码、Cookie、验证码和表单值。静态存档 HTML 的存在并不证明已具备安全、同次可重放的 DOM 包。

在独立离线进程中固定权重/图库/源码 SHA、CPU/GPU、线程、依赖、截图尺寸和缓存配置；阻断联网，输出到新的运行目录。不得占用/重启日常服务。先在开发数据确认执行脚本和失败处理，再冻结测试清单。两方案使用完全相同输入和模型资源，记录原始判定、联合建议、实际执行判定为三列；联合建议不能改写原始结果。

记录每一尝试，包括读取/解码失败、超时、初始化失败、无 Logo、拒识、缓存命中。计时拆分初始化、区域提议、检测、匹配、文字提取、规则、URL 子分析及总耗时。冷启动使用新独立进程单列；热态用固定乱序做三次配对运行，报告每样本中位数以及总体 P50/P95，失败计数不丢弃。三次重复不算三个独立样本。纯离线数据不报告“日常 Edge 耗时”。

## 指标定义及拒识处理

必须先报告各指标的标签资格分母、有效组数、排除数、失败数和覆盖率。主表按真实类别分别展示 block / allow / uncertain / error 四列，禁止把 uncertain 归为 allow、把错误响应伪装成安全。

| 指标 | 定义与条件 |
|---|---|
| 品牌确认 precision | 正确确认主要品牌数 / 所有具有裁决真值且实际确认品牌数；在真值为 unknown、mixed 或 third-party-only 的页面确认单一主要品牌计错，不按候选分数改真值 |
| 品牌确认 recall/coverage | 正确确认数 / 有可确认单一主要品牌的合格样本数；另报确认覆盖率、未知/混合负例的错误确认率 |
| 未确认比例 | 有效完成且 confirmed_brand=null / 有效完成数；另报 null 或失败 / 全部尝试数，避免失败被隐去 |
| 钓鱼 block precision | TP/(TP+FP)，TP=恶意真值且原判定 block，FP=正常真值且原判定 block |
| 端到端 block recall | TP/全部合格恶意样本尝试数；allow、uncertain、error 均是本轮未拦截，但分别列出，绝不据此把 uncertain 称为安全 |
| block F1 | 2PR/(P+R)，使用以上 precision 和意向评估 recall；无分母时为 null，不填 0 或 1 |
| 正常误拦率 | FP/全部合格正常样本尝试数，同时报告仅有效完成样本的 FP/正常有效完成数、allow/uncertain/error 分布和覆盖率 |
| 明确错误放行 | 恶意真值且 allow / 全部合格恶意尝试数；与未拦截率区分，不混入 uncertain |
| 耗时、失败率 | 热/冷及阶段 P50/P95；failed_attempts/all_attempts。失败/超时样本不从性能总体中静默删除 |

以上 block 指标是实际拦截效果，不是将三态输出强行转成“安全/恶意”的二分类正确率。可额外给出仅明确判定子集的结果，但不能替代主表。按主场景、真值类别、主要品牌、已知/图库外、登录角色和资源条件分组，同时给组级计数；不只报总体 accuracy。

置信区间以来源组为重采样单位，重复帧和派生图不增加有效 N。bootstrap 或二项区间需写明方法；小组样本不足时保留计数并标注不稳定，不据零误报宣称低风险。单来源作者标签可另列“按作者标签的诊断结果”，但不能冒充独立 precision/recall/F1/误报率。本次合格独立标签不足时所有这些独立指标留 null，并列原因。

## 冻结与验收门槛

本轮只冻结数据资产版本、方法和候选队列，不运行候选的新模型输出。先补标签与来源证明，再运行基线；基线和候选实验必须共享同一冻结清单。改动不得增加未知/多品牌/正常上下文的错误确认或覆盖原始执行判定；具体统计比较界限须在看锁定测试结果前预登记，不能看到结果后调整目标或挑样本。最终至少分别交付品牌层、拦截层、拒识层、性能层和证据资格表。
