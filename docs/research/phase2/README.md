# PhishLens 第二阶段：研究归档

第二阶段已于2026-10-27结束，以第十一项为最后一项。小Logo、文字声明及DOM原型保留研究成果，暂不生产接入。这里是脱敏的公开候选材料，不包含原始数据、截图、模型、图库或运行日志。

## 已完成

- 建立可追溯的数据分类、重复关系、泄漏隔离和独立评估协议。
- 对10748个来源样本建立既有盘点，10730张截图通过校验，18张不可读取/解码排除；3161条参考记录、320个品牌。8组完全重复，其中3组跨作者划分；95个样本97条标签或元数据问题；1912对近似候选。
- 将250个历史开发样本及其关联组排除出未见测试。43对像素一致但字节不同，15对辅助静态观察不等于独立人工复核。
- 完成有限真实视觉模型实验、文字声明严格副本和本地DOM证据一致性实验，保留失败和降级。

## 最终结果与边界

最后一次修正版单框匹配仅运行一次：4次嵌入全部返回、2项候选对齐完成；匹配2.733秒、0硬超时，因候选预算上限返回incomplete，完整区域匹配0次，无确认品牌。预算受控返回不等于完整识别通过。

独立合格评估样本仍为0，没有实际独立双人真值，不提供真实准确率、precision、recall或F1。截图定位分数、品牌相似度、文字声明和风险判定分别对待。独立headless Edge控制实验不能冒充日常生产扩展验收。
